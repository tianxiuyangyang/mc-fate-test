# 你的本命 MC 角色测试

> 🌐 **在线地址**：https://tianxiuyangyang.github.io/mc-fate-test/
> 📦 **仓库**：https://github.com/tianxiuyangyang/mc-fate-test

一个**浅色像素风**、单文件的《我的世界》本命角色测试网站：**3 个小游戏 + 7 道性格题**，通过**性格五维**从 **72 位 MC 角色**中判定你的本命，并给出专属称号、人物解读、危险等级、MCCP 搭档与可保存的海报。

配色为 MC 主题的**蓝绿灰浅色系**：白卡片 + 青绿强调色 + 浅灰蓝描边，背景是漂浮的像素云与上升光点，全部由 Canvas 绘制。

## 怎么打开

- 在线直接访问上面的「在线地址」
- 或者双击本地的 `index.html`（纯本地、零依赖、无需联网、无需服务器）

## 判定体系：性格五维

所有角色与玩家都由同样的 5 个维度描述（0–100）：

| 维度 | 含义 | 高分表现 | 低分表现 |
|---|---|---|---|
| **行动力** `action` | 出手快慢、爱不爱动弹 | 说走就走、反应快 | 慢节奏、悠哉 |
| **外向度** `extra` | 社交电量 | 爱热闹、要陪伴 | 内向、独处回血 |
| **侵略倾向** `aggro` | 面对冲突的态度 | 正面刚、爱破坏 | 回避冲突、温和 |
| **耐心 / 谨慎** `care` | 沉得住还是急 | 算得清、不冒险 | 冲动、坐不住 |
| **创造 / 守护** `build` | 建造与守护的倾向 | 爱搭建、爱收集、护短 | 破坏型、不恋物 |

判定方式：把 3 个小游戏的行为数据 + 7 道题的选项加分合成一个 5 维向量，归一化后与 72 个角色的 5 维坐标做**欧氏距离**比对，最近的那个就是你的本命。

## 完整体验流程（3 小游戏 + 7 道题，共 10 步）

| 步骤 | 内容 | 产出维度 |
|---|---|---|
| 1 | 小游戏 ①**快速挖方块**（10 秒） | 挖得多→行动力；不乱点→耐心；频繁点空→侵略 |
| 2–3 | 性格题 1–2（探索偏好 / 应对方式） | 行动力、外向、侵略、耐心、创造 |
| 4 | 小游戏 ②**躲避苦力怕**（10 秒生存） | 持续走位→行动力+外向；苟住→耐心；频繁被撞→侵略 |
| 5–6 | 性格题 3–4（他人印象 / 力量取向） | 同上 |
| 7 | 小游戏 ③**极速搭建**（4 秒自由摆放） | 堆高→侵略+创造；平铺整齐→耐心+创造；零散乱摆→外向；**围成封闭空间→内向+谨慎** |
| 8–10 | 性格题 5–7（耐性 / 环境偏好 / 规则观） | 同上 |
| — | 灵魂频率解析动画 → 结果页 | — |

每答完一题，右下角会触发一次 MC 粒子特效：颜色按该选项的主导维度变化（火花 / 气泡 / 火把 / 灵魂 / 树叶）。

## 结果页包含

- 超大角色像素立绘（9 类体型模板 + 每角色独立配色）+ 匹配度
- 专属**本命称号**（72 个互不重复，如「末地之主・孤高龙影」「随性爆炸・氛围制造师」）
- 3 段专属人物解读
- 你的**性格五维**数值 + 与角色本人的逐维对比（↑ 你更极端 / ↓ 更收敛 / ≈ 吻合）
- **MC 危险等级**（角色基础危险度 与 你本人的侵略、行动倾向加权）
- **MCCP 搭档**：在 72 角色中找距离最近且互选的一位
- **你的游玩风格**标签（稳准手 / 急性子 / 走位派 / 苟住流 / 高塔派 / 建筑师 / 筑巢者 / 随性派）
- 一键**复制结果** / **分享好友** / **保存海报 PNG** / **重新测试**

## 自测结果（最近一次）

- `tools/e2e-test.js`：**33 / 33 通过**，零 JS 报错。覆盖启动动画 → 3 小游戏 → 7 道题 → 结果页 → 海报 → 复制 → 重测 → 粒子特效 → 手机视口
- `tools/check-sprites72.js`：72 个精灵全部合法（着色量、构图饱满度、无重复），并输出总览图
- `tools/calibrate.js`：**45000 次答卷模拟，72 个角色全部可被命中**；理想剖面命中率 72/72
- `tools/check-poster.js`：72 张海报内容高度 1125–1140px，均在 1180px 画布内无溢出

## 目录结构

```
index.html                 站点本体（单文件，自包含，无任何外部依赖）
tools/deploy-github.js     一键部署到 GitHub Pages
tools/e2e-test.js          端到端回归测试（无头浏览器真实跑完整流程）
tools/check-sprites72.js   72 个像素精灵校验 + 输出总览图
tools/calibrate.js         计分标定：模拟答卷验证 72 角色可达性与分布
tools/check-poster.js      海报排版压测（72 个角色各画一张）
tools/export-poster.js     导出海报 PNG 供肉眼验收
tools/shot-games.js        抓取小游戏进行中的截图
screenshots/               截图与精灵总览图
```

```bash
node tools/check-sprites72.js   # 校验 72 个精灵
node tools/calibrate.js         # 校验 72 角色可命中率
node tools/e2e-test.js          # 真机跑完整流程（33 项断言）
node tools/check-poster.js      # 压测 72 张海报排版
```
