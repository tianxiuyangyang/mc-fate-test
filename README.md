# 你的本命 MC 角色测试

一个**浅色像素风**、单文件的《我的世界》本命角色测试网站：**3 个小游戏 + 5 道性格题**（共 8 步，约 70 秒），综合判定 12 位高人气 MC 角色中属于你的那一位，并给出专属称号、人物解读、危险等级、MCCP 搭档与可保存的海报。

配色为 MC 主题的**蓝绿灰浅色系**：白卡片 + 青绿强调色 + 浅灰蓝描边，背景是漂浮的像素云与上升光点，全部由 Canvas 绘制。

## 怎么打开

直接双击 `index.html` 即可（纯本地、零依赖、无需联网、无需服务器）。

> 想用本地服务器打开也行：`npx serve .` 或 `python -m http.server`，效果一致。

- 建议用 Chrome / Edge / Firefox 最新版
- 手机浏览器同样可用（390px 视口已适配，小游戏支持触屏）
- 首次点击页面任意位置后音效才会启用（浏览器的自动播放限制）

## 结果页包含

- 超大角色像素立绘（224×224，纯 Canvas 像素绘制）+ 匹配度
- 专属**本命称号**，例如「深渊主宰・天际孤王」「随性爆炸・氛围制造师」「静默独行・暗夜行者」
- 专属人物解读（每个角色 3 段定制文案）
- 你的人格六维雷达数值（活跃 / 耐心 / 冒险 / 内敛 / 力量 / 暗夜）
- MC 危险等级（角色基础危险度 + 你本人的力量与冒险倾向加权）
- 匹配你的 **MCCP 搭档**（12 角色两两配对）
- 一键**复制结果** / **分享好友** / **保存海报 PNG** / **重新测试**

海报为 720×1180 的独立 PNG，含立绘、称号、解读、危险条、六维条与搭档信息。

## 角色库（12 位）

史蒂夫 · 爱丽克丝 · 苦力怕 · 末影人 · 僵尸 · 骷髅 · 凋灵 · 末影龙 · 村民 · 女巫 · 幻翼 · 海豚

每个角色都由一个六维性格向量定义：

```
向量 = [活跃度, 耐心值, 冒险欲, 内敛度, 力量感, 暗夜倾向]   取值 0–100
```

## 判定逻辑（可解释、可复现）

1. **答题**：5 道题共 18 个选项，每个选项直接给六维向量加减分。
2. **小游戏**：三个游戏各自产出行为指标，再换算成向量增量：
   - 挖方块 → 命中数（活跃）、矿石数（力量）、命中率（耐心）
   - 躲苦力怕 → 移动距离（活跃）、惊险次数（冒险）、存活时长与剩余生命（耐心）
   - 极速搭建 → 方块数与高度（力量）、平铺比例（耐心）、悬空与色彩种类（冒险）
3. **归一化**：原始分按各维标定上限换算成人格百分制，保证「分数可读、区分度足够」。
4. **比对**：与 12 个角色向量做归一化欧氏距离，距离越小越像；小游戏的行为偏置（如「建筑师」「走位」「爆炸」「高塔」「混沌」）再给对应角色小幅加成。
5. **去重**：以你的答案指纹作为确定性随机种子做极小扰动，避免同分并列，并保证同一套答卷结果稳定不变。

结果分布经 4000 次模拟标定：村民/苦力怕/僵尸/海豚等「低强度」角色较常见，末影龙、女巫、末影人属于需要刻意为之的稀有结果 —— 但每个角色**都可被精准命中**（12 个理想剖面 12/12 正确识别）。

## 音效

全部由 Web Audio 程序化合成（方波点击音、挖掘噪声、爆炸声、胜利音阶、循环环境音），没有任何音频文件。右上角「♪ 音效」可随时开关。

## 目录结构

```
index.html                 站点本体（单文件，自包含，无任何外部依赖）
tools/e2e-test.js          端到端回归测试：无头浏览器真实点完 3 个游戏 + 5 道题
tools/check-sprites.js     像素精灵数据校验（16×16 / 调色板 / 左右对称）
tools/check-poster.js      海报排版压测：12 个角色各画一张，确认不溢出画布
tools/export-poster.js     导出海报 PNG 供肉眼验收
tools/fix-sprites.js       精灵数据对称化工具（改像素数据时用）
screenshots/               测试自动生成的截图与海报预览
```

开发工具需要 Node 18+ 与本机安装 Edge 或 Chrome：

```bash
node tools/check-sprites.js   # 校验 12 个像素精灵数据
node tools/e2e-test.js        # 真机跑完整流程（31 项断言）并输出截图
node tools/check-poster.js    # 压测海报排版
node tools/export-poster.js   # 导出海报预览图
```

## 自测结果（最近一次）

- `e2e-test.js`：**31 / 31 通过**，无 JS 报错；覆盖启动动画 → 3 个小游戏 → 5 道题 → 结果页 → 海报 → 复制 → 重测 → 手机视口
- `check-sprites.js`：12 个精灵全部合法（尺寸、色键、对称、着色量）
- `check-poster.js`：12 张海报内容高度 1090–1125px，均在 1180px 画布内，无溢出
- 计分分布经 4000 次模拟标定；12 个角色的「理想剖面」全部能被正确命中（12/12）

## 小彩蛋

在地址栏的 `index.html` 后面加上 `#demo`，可直接跳到结果页看效果；加上 `#shot` 效果相同并额外关闭全部动画（供自动化截图使用）。两者都不影响正常使用。
海报与精灵的自动化测试依赖这个入口，若要删除请保留 `window.__makePosterFor`。
